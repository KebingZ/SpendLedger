# Security policy

This is a portfolio project and not a hosted payment service. Do not submit real cardholder data,
API keys, credentials, or production settlement files.

To report a vulnerability, open a private security advisory in the GitHub repository rather than a
public issue. Include reproduction steps, affected version, impact, and any proposed mitigation.

The example Kubernetes Secret and local development passwords are placeholders. Production use
requires a managed secret store, key rotation, TLS, network egress policy, workload identity,
database encryption, backups, retention controls, and independent security review.
